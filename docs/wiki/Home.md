# Ramrattan Canvas

Ramrattan Canvas is a local, single-user Kanban board for GitHub issues and pull requests, from The Ramrattan Consultancy.  GitHub stays authoritative for state, merges, and completion dates.  Canvas adds local planning: lanes, card order, priorities, workstreams, notes, and dependencies, saved separately for each repository in your browser.  It never writes to GitHub.
