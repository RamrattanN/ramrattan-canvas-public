# Wiki source

These files are the source for the GitHub Wiki of the public repository, `RamrattanN/ramrattan-canvas-public`.  Each file name becomes a page title, for example `Getting-Started.md` becomes **Getting Started**.  This README is not a Wiki page.

GitHub creates the Wiki repository only after its first page is saved in the web interface.  To publish:

1. Open the repository's **Wiki** tab and save any first page.
2. Clone `https://github.com/RamrattanN/ramrattan-canvas-public.wiki.git`, copy in every `.md` file from this folder except this README, commit, and push.

Images point to `docs/demo/images/` on the public repository's `main` branch.
